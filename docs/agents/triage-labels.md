# Triage labels

The engineering skills use five canonical triage roles. This table maps each role to the corresponding GitHub label in this repository.

| Canonical role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | A maintainer needs to evaluate the issue |
| `needs-info` | `needs-info` | The issue is waiting for information from its reporter |
| `ready-for-agent` | `ready-for-agent` | The issue is fully specified and ready for an AFK agent |
| `ready-for-human` | `ready-for-human` | The issue requires human implementation or intervention |
| `wontfix` | `wontfix` | The issue will not be actioned |

When a skill refers to a triage role, use the GitHub label in the second column. Update this mapping if the repository vocabulary changes instead of creating synonymous labels.
