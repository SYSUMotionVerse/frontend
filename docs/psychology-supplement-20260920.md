# 基线量表补充

新增独立的 Vue 3 / uni-app Stroop 界面，沿用现有奶油色卡片、深色标题和粉色按钮。辨色通过后完成 10 试次，展示准确率、完成时间和全部试次的平均反应时间；按最终需求不做等级评定。后端保存成功后点击“完成并继续”结束基线。

中途离开或切后台时重新开始；已经完成但上传失败的成绩按学号和量表 ID 保存在本机，下次可原样重试。计时由客户端记录，存在设备显示更新延迟，不能等同于实验室级计时。

MSES-9 使用 0—10 整数刻度滑块，拖动或点击刻度后仍需手动点击“下一题”。默认显示 0 不会自动计为已答，点击 0 刻度可以明确选择 0 分；提交仍使用原有选项 ID。

后端迁移自动新增自尊量表和 Stroop，并修改 MSES 展示配置，重复部署不会重复导入。小程序构建还需通过微信开发者工具发布；自动化组件测试不能替代 Nova14 等真机上的显示与触控验证。
