# 知情同意书签署

资料及邀请码验证成功后进入 `pages/access/consent`，完成签署后由后端测量进度决定进入基线问卷或首页。已注册用户在启动检查中也会被要求补签当前版本。

页面按原件逐页展示，可点击放大。研究者姓名和北京时间日期自动填在底部对应区域；受试者签名使用虚线框，点击打开半屏画布。画布提示用清晰楷体写登记姓名，导出白底 PNG 和 RGBA 像素。

优先调用微信 VisionKit 静态 OCR，基础库最低 2.27.0；不支持、无结果或超时会走免费服务器 OCR。端侧结果不能代替服务器校验。服务器接收并归档实际图片，再识别完整姓名；失败保留重签界面，未识别成功不能确认。

签名验证成功后仍需本人勾选已阅读并自愿同意，点击“确认签署并继续”。签署成功生成保留原文、签名及日期的 PDF。请求超时可重试，后端以用户和上传请求 UUID 保证幂等。

服务端文档版本或登记姓名发生变化时须重新加载并签署。COS 图片链接有效期 15 分钟。发布时务必与后端同步上传生产 build；旧版不含签署入口，无法完成强制补签。

真机验收应覆盖：iOS、安卓和鸿蒙画布；旧微信不支持 VisionKit 时的服务器识别；字迹模糊、姓名不一致、断网重试；完整阅读、确认签署及原有问卷进度恢复。OCR 仅核对文字，不提供身份鉴定保证。
