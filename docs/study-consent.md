# 知情同意书签署

资料及邀请码验证成功后进入 `pages/access/consent`，完成签署后由后端测量进度决定进入基线问卷或首页。已注册用户在启动检查中也会被要求补签当前版本。

页面按原件逐页展示，可点击放大。研究者姓名和北京时间日期自动填在底部对应区域；受试者签名使用虚线框，点击打开半屏画布。画布提示用清晰楷体写登记姓名，按记录的笔画生成白底 PNG 和 RGBA 像素，完成时不调用原生画布读像素、导出或文件接口。

半屏覆盖自定义导航标题，支持点击外部关闭及滑入滑出动画。底部“重写、撤回、完成”宽度为 1:1:2；一次撤回移除从落笔到抬笔的整笔。只有点击“完成”并验证通过才在当前页面内存中保存图片和笔画；点击外部关闭丢弃未验证的修改，重新打开恢复上一次验证通过的签名，没有已保存签名则为空白。重新加载文档时清空本地签名。

定位使用文档页面的比例坐标，字号依据图片实际显示宽度、原文字号和填写区宽高共同计算。日期填写在原文“日期：”之后的空白区域，不重复标签、不换行。每次画笔移动均单独提交上一点到当前点的线段，避免 Android 原生画布刷新后丢失路径起点。

只调用微信 VisionKit 静态 OCR，基础库最低 2.27.0。用户界面统一显示“处理中…”；失败时只要求重写，不显示内部识别、网络或超时细节。画板内的成功或失败均不上传后端。后端只在正式提交时保存并核对前端上报的识别文字，不部署服务器 OCR，也不调用付费云 OCR。

画板在滑入结束后移除变换，通过小程序视图查询确认已渲染后才创建绘图上下文；关闭或卸载会使待初始化任务失效。画板就绪后再预热识别会话，在用户书写期间完成启动，点击“完成”复用该会话。预热不在打开面板的点击处理器里启动，取消的画板就绪通知不能创建会话。识别期间保留同一个原生画布及原笔画，不替换成图片、不重建绘图上下文。检查基础库至少为 2.27.0；创建参数与已知正常版本 `6cae89b` 一致，仅为 `{ track: { OCR: { mode: 2 } } }`，不指定 AR 版本、不调用 AR 版本支持探测。

正常返回的会话保持到离开页面复用，不在结果返回后立即销毁；失败或取消时丢弃会话，重试须等旧会话释放完成。传给原生接口的图片缓冲区保留到结果返回或会话释放，避免临时副本在异步处理期间失去引用。与正常版本一致，裁剪输入的副本在会话启动完成后分配，避免增加启动期间的内存占用；启动前仅检查尺寸和缓冲区长度。识别输入裁掉空白边缘并将过大输入等比例缩小。验证通过后另行裁剪原始 PNG 的空白边缘，按实际图片比例缩窄文档中的签名框，保持高度和左边缘不变。启动给予 15 秒、识别 10 秒，外层保留 30 秒兜底；旧回调不能影响下一次签名。

画板完成事件只传短编号，不将 PNG 或 RGBA 像素数组交给组件事件桥。页面与画板通过同一 JS 模块中的页面专属临时通道交接图片，消费时保留原始 typed array 且不复制；同一个编号只能消费一次。关闭、重开、重新加载或卸载页面时清理未消费数据；临时通道只在内存中，不写文件、不存本地签名历史、不上传。回归测试将完成事件按原生桥边界进行 JSON 往返，检查 payload 小于 128 字节、像素保持同一缓冲区，以及取消后迟到的事件不能开始识别。以 319×190 画板的双倍像素为例，旧事件的 JSON 表示约 12.5 MB；新事件仅含短编号。这是传输体积测量，不等同于真机实际桥实现的内存测量或原生闪退根因证明。

调试控制台 `[consent-signature]` 输出原生创建、启动、识别、释放调用前后的阶段、`elapsed_ms` 和处理后的尺寸，不输出姓名或图片，不向后端上传错误历史。本地仅覆盖保存最新一条阶段元数据；重新进入页面输出 `previous_native_stage`、实际 `SDKVersion` 和微信版本，使原生闪退后也能确定上次停在哪一步及运行环境。计时与裁剪可在本地回归测试中验证；设备实际识别成功率及闪退是否消失须以真机复测为准。接口参考：[微信静态 OCR 文档](https://developers.weixin.qq.com/miniprogram/dev/framework/open-ability/visionkit/ocr.html)。

签名验证成功后仍需本人勾选已阅读并自愿同意，点击“确认签署并继续”，此时才调用 `POST /api/users/consent/submit/` 上传签名并正式签署。签署成功生成保留原文、签名及日期的 PDF。请求超时可重试，后端以用户和上传请求 UUID 保证幂等。

服务或网络导致正式提交失败时保留已验证签名，提示再次提交，不要求重写；错误带有请求编号时在提示和控制台记录编号、状态码及提交阶段，不记录姓名或图片。

服务端文档版本或登记姓名发生变化时须重新加载并签署。COS 图片链接有效期 15 分钟。发布时务必与后端同步上传生产 build；旧版不含签署入口，无法完成强制补签。

真机使用时需留意：iOS、安卓和鸿蒙画布；旧微信不支持 VisionKit 时的内部错误码和统一重写提示；字迹模糊、姓名不一致、断网重试；完整阅读、确认签署及原有问卷进度恢复。OCR 仅核对文字，不提供身份鉴定保证。
