# 动作标准文件工作台使用手册

动作标准文件工作台从本地视频提取人体姿态角度，并为每个视频生成一个动作标准 JSON 文件。工具在浏览器本地完成视频解码、BlazePose 推理和文件打包，不会把视频或分析结果上传到后端、对象存储或其他外部服务。

## 适用场景

使用这个工具可以完成以下工作：

- 一次导入多个标准动作视频。
- 为每个视频填写动作名称、动作 ID、动作类型和标注信息。
- 截取视频中需要参与分析的时间范围。
- 添加按视频时间触发的语音提示。
- 提取 9 个关节或躯干角度，生成 `schema_version: "0.4"` 的动作标准文件。
- 将所有已生成的 JSON 文件打包为一个 ZIP 文件。

工具是独立的本地 H5 工作台，不属于微信小程序页面。使用工具不需要微信开发者工具，也不受 `touristappid` 限制。

## 启动工具

首次使用时，在仓库根目录安装项目固定的运行环境和依赖：

```bash
mise install
pnpm install
```

启动动作标准文件工作台：

```bash
pnpm dev:action-tool
```

浏览器打开以下地址：

```text
http://127.0.0.1:4174/action-tool.html
```

页面右上角显示“姿态模型就绪”后，工具可以开始分析视频。模型文件来自仓库中的 `models/pose/`，启动工具时不需要从 OSS 下载模型。

## 生成动作文件

### 1. 导入视频

点击“导入视频”或“选择视频”，选择一个或多个本地视频。你也可以把视频文件拖入工作台。

导入操作只为浏览器创建本地文件引用。工具不会复制视频到项目目录，也不会向服务器发送视频内容。

建议使用浏览器可以直接解码的 MP4、MOV 或 WebM 文件。不同操作系统支持的视频编码可能不同，H.264 编码的 MP4 通常兼容性最好。

### 2. 填写动作标注

从左侧视频队列选择一个文件，然后填写右侧的动作信息。

| 字段 | 用途 | 填写建议 |
| --- | --- | --- |
| 动作名称 | 展示动作的人类可读名称 | 使用训练安排中显示的完整动作名 |
| 动作 ID | 标识动作并作为 JSON 文件名 | 保持唯一、稳定，避免使用 `/`、`:` 等文件名字符 |
| 动作类型 | 描述动作的时间结构 | 重复动作选 `repetitive`，保持动作选 `hold`，单次动作选 `single` |
| 标注人 | 记录文件创建者 | 填写姓名或团队账号 |
| 开始时间 | 分析片段的起点，单位为秒 | 默认从 `0` 秒开始 |
| 结束时间 | 分析片段的终点，单位为秒 | 默认使用视频完整时长 |
| 备注 | 保存额外的标注说明 | 记录拍摄方向、动作版本或特殊处理 |

开始时间必须小于结束时间，结束时间不能明显超过视频时长。工具允许浏览器解码产生的少量毫秒级时长误差。

### 3. 添加语音提示

点击“语音提示”区域的“添加”，填写提示时间和提示文本。提示时间使用视频时间轴的秒数，导出时会按时间从早到晚排序。

语音提示不会影响角度分析。空白提示不会写入导出的 JSON。

### 4. 分析视频

点击“分析当前视频”处理当前文件，或点击底部的“分析剩余 N 个视频”依次处理队列中尚未完成的文件。

工具以 10 FPS 采样视频。例如，30 秒视频通常生成约 300 帧角度数据。分析速度取决于视频分辨率、时长、浏览器和显卡性能，分析时间不一定等于视频播放时长。

分析过程中可以取消任务。取消后，工具保留视频和标注信息，你可以稍后重新分析。

修改动作标注或截取范围后，文件状态会恢复为“待分析”。再次点击分析，工具会使用新的设置重新生成结果。

### 5. 导出全部文件

视频状态显示“已生成”后，右上角的导出按钮会显示可导出的文件数量。点击“导出 N 个文件”，浏览器会下载一个类似以下名称的 ZIP 文件：

```text
action-standard-2026-07-22.zip
```

ZIP 中的每个视频对应一个 JSON 文件。文件名来自动作 ID，工具会自动替换不适合文件名的字符。

## 输出数据

工具按照参考文件 `action_standard.json` 的 0.4 schema 输出数据。每个文件包含以下主要字段：

```json
{
  "schema_version": "0.4",
  "action_id": "action-id",
  "action_name": "动作名称",
  "action_type": "repetitive",
  "fps": 10,
  "angle_unit": "radian",
  "angle_names": [
    "left_elbow",
    "right_elbow",
    "left_shoulder",
    "right_shoulder",
    "left_hip",
    "right_hip",
    "left_knee",
    "right_knee",
    "torso_rotation"
  ],
  "standard_sequence": [],
  "angle_rules": {},
  "tts_cues": [],
  "metadata": {}
}
```

`standard_sequence` 中的每一行对应一个采样帧，每行包含 9 个弧度值。数值顺序与 `angle_names` 完全一致。

工具对偶发缺失的角度执行前后帧插值，再使用 5 帧移动平均减少抖动。如果某个角度在整个截取范围内都无法识别，工具会停止生成该视频的文件并显示缺失角度。

默认角度容差为 20 度，对应约 `0.34906585` 弧度。肩、髋和躯干旋转的默认权重为 `2/14`，肘和膝的默认权重为 `1/14`，与参考动作标准文件保持一致。

## 本地处理与隐私

工具只访问以下本地资源：

- 你通过文件选择器导入的视频。
- 仓库中的 BlazePose 模型文件。
- 浏览器内存中的姿态结果和生成的 JSON。

工具不调用学生端后端 API，不需要登录，也不需要配置 OSS、COS 或请求域名白名单。关闭或刷新页面后，浏览器会释放当前视频队列；工具不会自动保存未导出的结果。

## 常见问题

### 页面显示“模型加载失败”

确认 `models/pose/detector/model.json` 和 `models/pose/landmark_lite/model.json` 存在，然后重新运行 `pnpm dev:action-tool`。如果文件存在，刷新页面并检查浏览器是否允许 WebGL；工具在 WebGL 不可用时会尝试 CPU 后端。

### 页面显示“截取时间范围无效”

确认开始时间不小于 `0`，结束时间大于开始时间，并且结束时间没有明显超过视频总时长。重新导入视频会恢复默认的完整时长范围。

### 页面显示某些角度在整段视频中不可见

确认截取范围内可以持续看到完整人体，尤其是肩、肘、腕、髋、膝和踝。避免身体离开画面、关节长时间遮挡、逆光或人物尺寸过小，然后重新拍摄或调整截取范围。

### 视频无法读取或预览

浏览器可能不支持视频使用的编码。将视频转为 H.264 编码的 MP4 后重新导入。

### 分析速度较慢

姿态分析需要对每个采样帧运行模型。缩短截取范围、降低原始视频分辨率或使用支持 WebGL 的设备可以减少处理时间。批量分析会按队列顺序处理视频，避免多个模型任务同时争用显卡内存。

### 导出按钮不可用

至少需要一个视频处于“已生成”状态才能导出。检查左侧队列中的错误状态，修正标注或视频问题后重新分析。

## 构建静态版本

运行以下命令生成静态构建：

```bash
pnpm build:action-tool
```

构建结果位于 `dist/action-tool/`。静态版本需要通过 HTTP 服务器访问，不能直接双击 HTML 文件，因为浏览器需要通过 HTTP 加载 JavaScript 和本地姿态模型。
