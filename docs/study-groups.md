# 邀请码注册与训练组别

注册基本信息新增必填邀请码。服务端自动分组，接口返回的 `study_group.allowed_modalities` 决定可进入的训练形式；邀请码只用于提交注册，不保留在本地资料中。

默认邀请码：`test-traditional`（传统体育养生）、`test-resistance`（自重抗阻）、`test-stairs`（跑楼梯）、`test-questionnaire`（仅问卷）、`test-all`（全部训练）。管理员可在 Dashboard 修改邀请码和权限。已有用户由数据库迁移加入全权限组。

问卷组首页和训练选择页保留问卷入口、显示无需训练提示。四个测量时点的心理问卷及每日久坐问卷均可正常填写。久坐提醒纳入站内消息列表。已开放训练的日目标按组别运动形式数量计算。

本地入口检查改善操作提示，服务端对视频、编排、凭据和成绩提交进行最终鉴权。跑楼梯开始前调用 `POST /api/exercises/stairs/training-access/`；等待期间退出页面会取消启动。

发布顺序：后端自动部署完成迁移后，上传生产构建 `dist/build/mp-weixin`。验收各邀请码注册、仅显示对应运动形式、问卷组不能启动训练、无效邀请码保留填写内容并显示服务端提示，以及管理员修改权限后的接口拒绝行为。
