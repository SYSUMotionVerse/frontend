# Sport Snack Frontend

## Project Overview / 项目简介
This is the frontend for the student-side Sport Snack mini-program prototype, built with uni-app + Vue 3 + TypeScript. The primary build target is the WeChat Mini Program.
这是基于 uni-app + Vue 3 + TypeScript 开发的学生端“运动零食”小程序原型的前端项目，主要构建目标为微信小程序。

## Tech Stack / 技术栈
- uni-app
- Vue 3
- TypeScript
- Vitest
- UnoCSS
- pnpm

## Prerequisites / 环境准备
Ensure the following tools are installed before starting:
开始前请确保已安装以下工具：
- Node.js
- pnpm
